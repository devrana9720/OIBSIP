# 🚀 OIBSIP Internship Projects

Welcome to my **OIBSIP Internship Projects** repository. This repository contains Java applications developed as part of my internship to practice object-oriented programming, application development, database connectivity, and software development workflows.

## 📂 Projects

### 1. 🚆 RailPlan — Online Reservation System

A Java Swing desktop application that simulates a train reservation workflow, including user registration, login, train search, reservation booking, reservation history, and cancellation using MySQL.

**Technology Stack:**
- Java 21
- Java Swing and AWT
- JDBC
- MySQL 8
- Apache Maven
- JUnit 5
- Git and GitHub

**Key Features:**
- User registration and login
- Train search with simulated train results
- Reservation booking and database storage
- Reservation history and PNR-based lookup
- Reservation cancellation
- Input validation and database connectivity

**Project Links:**

- [Open Online Reservation System](./online-reservation-system/)
- [Read Online Reservation System Documentation](./online-reservation-system/README.md)

---

### 2. 🏧 ATM Interface — Java Console Application

A console-based ATM simulation developed using Java. It demonstrates authentication, account balance management, deposits, withdrawals, money transfers, and transaction history.

**Technology Stack:**
- Java 21
- Java Collections
- Scanner for console input
- LocalDateTime for transaction timestamps
- Git and GitHub

**Key Features:**
- Account ID and PIN authentication
- Three incorrect PIN attempts limit
- Deposit and withdrawal operations
- Money transfers between sample accounts
- Transaction history
- Input validation and insufficient-funds handling
- Menu-driven console interface

**Project Links:**

- [Open ATM Interface](./atm-interface/)
- [Read ATM Interface Documentation](./atm-interface/README.md)
